  - "Learn More": links to Wikipedia, NASA Image Library, NASA Mars Exploration, Google Mars (at that place), NASA Mars Trek.
Code: search "PHOTOS + LEARN MORE" in map.html. Add a site's photo search words/Wikipedia page in the MORE_INFO list.
